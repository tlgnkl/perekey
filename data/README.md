# data/

Здесь лежат данные, которые правят люди. Внешние словари и корпуса сюда не
кладём: их скачивает `scripts/fetch-data.sh` в `.build/data-cache`. Источники и
лицензии — в `SOURCES.md`.

Сборщик `perekey-model` читает внешние данные, потом применяет списки отсюда.
CI пересобирает модель и прогоняет отложенный корпус на каждый PR, который
трогает `data/`.

## Раскладка

```
data/
├── SOURCES.md          источники и лицензии
├── README.md           этот файл
├── ru/
│   ├── add.txt         слова, которых нет во внешних словарях
│   ├── remove.txt      ошибки внешних словарей: формы, которых нет в языке
│   ├── rank.txt        ручная поправка ранга частоты
│   ├── abbrev.txt      аббревиатуры, которые нельзя переключать: «ГОСТ», «МФЦ»
│   └── keep.txt        слова, которые никогда не переключаются автоматически
├── en/
│   └── …               те же файлы
└── mixed/
    └── keep.txt        строки, верные в обеих раскладках: «iPhone», «Wi-Fi»
```

Файла может не быть — тогда список пуст.

## Формат

- UTF-8, NFC, перевод строки LF.
- Одна запись на строку. `#` до конца строки — комментарий.
- Слова в нижнем регистре, кроме `abbrev.txt` и `mixed/keep.txt`: там регистр
  важен.
- «ё» пишем как «ё». Сборщик сам добавляет вариант с «е».
- `rank.txt`: `слово<TAB>ранг`, ранг 0–255, 255 — самое частое.
- Строки отсортированы (`LC_ALL=C sort -u`). CI проверяет сортировку и дубли.
- Первая строка — SPDX-заголовок, например
  `# SPDX-License-Identifier: GPL-3.0-or-later`.

## Правила для PR

1. Одна тема — один PR: «добавить 20 слов из IT-жаргона», а не всё подряд.
2. В описании PR укажите, откуда слова. Копировать из чужих словарей нельзя,
   если их лицензии нет в `SOURCES.md`. Словари Caramba нельзя никогда.
3. Слово из 1000 самых частых в `keep.txt` — только с объяснением в PR: оно
   перестанет исправляться у всех.
4. CI пишет, как правка сдвинула ложные срабатывания и полноту.

## Открытый вопрос

Модель собирается из данных под CC BY-SA 4.0. Если списки отсюда только под
GPL-3.0-or-later, модель целиком будет только под GPLv3. Чтобы модель
оставалась под CC BY-SA 4.0, правки можно принимать под
`GPL-3.0-or-later OR CC-BY-SA-4.0`. Решаем вместе с вопросами из
`SOURCES.md`, до первого внешнего PR.
