# План Perekey

Perekey — свободный автоматический переключатель раскладки для macOS.
Ориентир по функциям — Caramba Switcher, но с современным интерфейсом,
гибкими сочетаниями клавиш и без подписки.

## Принятые решения

| Вопрос | Решение | Почему |
|---|---|---|
| Имя | Perekey | «Переключить» + key. На GitHub нет проектов с таким именем |
| Лицензия | GPL-3.0-or-later | Форк не может стать закрытым платным клоном. Совместима с данными под CC BY-SA 4.0 |
| Платформа | Только macOS 14+ | `MenuBarExtra`, Observation, `SMAppService`. Windows не нужна |
| Язык | Swift 6, строгая конкурентность | Один инструмент сборки. Ядро без AppKit, его легко тестировать |
| Сборка | SwiftPM + `scripts/bundle.sh` | Нет `.xcodeproj`, нет конфликтов `.pbxproj` в PR. Собирается без Xcode |
| Тесты | Swift Testing | `scripts/test.sh` чинит запуск под Command Line Tools |
| Распространение | Developer ID + нотаризация, DMG, Homebrew cask, Sparkle 2 | Event tap проще работает вне песочницы App Store |
| Bundle ID | `app.perekey.Perekey` | Менять нельзя после первого релиза: macOS привязывает к нему выданные права |

## Чистая комната

- Функции Caramba Switcher изучены по поведению и строкам интерфейса. Код и
  данные не декомпилировались.
- Правила и словари Caramba (`latest.clm`, `caramba.redb`) не копируем и не
  используем для обучения.
- Название и логотип Caramba не используем.
- Источник и лицензию каждого словаря записываем в `data/SOURCES.md`.

| Функция | Этап |
|---|---|
| Любое сочетание на любое действие, пресеты «как в Windows» | 1 |

## Сочетания клавиш

### Действия

| Действие | По умолчанию |
|---|---|
| Сменить раскладку по кругу | Shift (одно нажатие) |
| Включить конкретную раскладку | не задано |
| Перенабрать последнее слово или выделение | Shift дважды |
| Включить или выключить автопереключение | левый ⇧ + правый ⇧ |
| Вставить без форматирования | ⌘⇧V |

### Пресеты

| Пресет | Смена раскладки |
|---|---|
| Как в Caramba | Shift |
| Как в Windows | ⌥⇧ |
| Как в Windows, вариант | ⌃⇧ |
| Привычка с Windows на Mac | ⌘⇧ |
| Раздельно | правый ⌘ → English, правый ⌥ → Русский |
| Caps Lock | Caps Lock, мгновенно |

### Правила распознавания

Логика уже есть в `Sources/PerekeyCore/ChordDetector.swift` и покрыта тестами.

- Сочетание из одних модификаторов срабатывает на **отпускание**.
- Оно срабатывает, только если между нажатием и отпусканием не было другой
  клавиши или клика. Поэтому ⌘⇧4 не считается ⌘⇧, а Shift+A не меняет раскладку.
- Нажатие дольше 0,8 с не считается.
- Двойное нажатие — два одинаковых нажатия в пределах 0,4 с.
- Одиночное действие срабатывает сразу, без ожидания второго нажатия.
  Действие на двойное нажатие само ставит нужную раскладку.
- Левый и правый модификаторы различаются.
- Caps Lock переназначаем в F18 через `hidutil`, чтобы индикатор не загорался.
- Обычные сочетания (⌃Space и т. п.) записывает свой рекордер. Он предупреждает
  о конфликте с системой: ⌘Space — Spotlight, ⌃Space — системная смена
  источника ввода. Библиотека `KeyboardShortcuts` не подходит: она не умеет
  сочетания из одних модификаторов.

## Устройство

```
┌─ Perekey (приложение) ─────────────────────────────────┐
│ SwiftUI: MenuBarExtra, настройки, онбординг, подсказка  │
│ Настройки и исключения: JSON в Application Support     │
└──────────────┬─────────────────────────────────────────┘
               │
┌─ PerekeyInput (системный слой, этап 1) ─▼──────────────┐
│ EventTap — CGEventTap, буфер слова, перенабор          │
│ InputSources — TISCreateInputSourceList / Select        │
│ KeyTranslator — UCKeyTranslate: клавиша → символ        │
│ SecureInput — IsSecureEventInputEnabled                 │
│ Permissions — AXIsProcessTrusted, Input Monitoring      │
└──────────────┬─────────────────────────────────────────┘
               │
┌─ PerekeyCore (чистая логика, без AppKit) ─▼────────────┐
│ ChordDetector — сочетания из модификаторов   ✔ готово   │
│ LayoutMap — таблица символов между раскладками          │
│ WordBuffer — текущее слово, границы слова               │
│ Classifier — n-граммы + словарь, порог уверенности      │
│ Exceptions — слова и программы                          │
│ Yofikator, DoubleCaps — правки текста                   │
└────────────────────────────────────────────────────────┘
```

Ядро не знает про macOS API. Системный слой переводит события `CGEvent` в
простые значения (`ModifierKey`, нажатый символ, id программы) и передаёт их в
ядро. Поэтому почти всю логику можно проверить юнит-тестами.

### Этап 0. Фундамент

- [x] Имя, лицензия, стек

- [x] `scripts/test.sh` запускает тесты под Xcode и под Command Line Tools
- [x] CI в GitHub Actions
- [ ] Создать репозиторий на GitHub, ветку по умолчанию `main`
- [ ] Аккаунт Apple Developer ($99/год) и сертификат Developer ID
- [ ] Решить: CLA или DCO для внешних PR

### Этап 1. Ручное переключение (MVP)

1. Сделать `PerekeyInput`: event tap на `keyDown`, `flagsChanged` и клики мыши.
2. Подключить `ChordDetector` к event tap.
3. Сделать `LayoutMap` из реальных раскладок системы через `UCKeyTranslate`.
4. Сделать `WordBuffer`: сбрасывать слово на клике, стрелках, смене программы.
5. Перенабрать слово: Backspace × N, сменить раскладку, ввести символы заново.
   Задержки брать из настроек программы.
6. Перенабрать выделение: копировать, конвертировать, вставить, вернуть буфер обмена.
7. Определять Secure Input и показывать понятное предупреждение.
8. Сделать онбординг: запрос доступа и проверка, что доступ выдан.
9. Сделать экран сочетаний с пресетами и рекордером.

Готово, когда: Shift дважды исправляет «ghbdtn» на «привет» в Safari, Notes,
Telegram, VS Code и Terminal.

### Этап 2. Автопереключение

1. Собрать данные: частотные словари и n-граммы ru и en из открытых корпусов
   с совместимой лицензией.
2. Сделать `Classifier`: оценка «слово на этом языке» по n-граммам и словарю.
3. Задать консервативный порог. Короткие и неоднозначные слова не трогать.
4. Не трогать код, URL, пути, email, слова с цифрами.
5. Сделать исключения для слов и программ, экран управления ими.
6. Добавить пункт меню «Не переключать в этой программе».
7. Собрать корпус тестов на ложные срабатывания и прогонять его в CI.

Готово, когда: на тестовом корпусе ложных срабатываний меньше 0,1 %.

### Этап 3. Дополнительные функции

1. Исправлять «ДВойные» заглавные.
2. Ёфикатор по словарю однозначных случаев.
3. Звук переключения, выбор своего файла.
4. Вставка без форматирования.
5. Локальная статистика с графиком (Swift Charts).

### Этап 4. Дизайн

1. Меню в строке меню: текущая раскладка, быстрые переключатели функций.
2. Окно настроек с боковой панелью и плитками функций. Liquid Glass на macOS 26+.
3. Подсказка у курсора после автопереключения (`NSPanel` у позиции каретки через AX).
4. Онбординг в 2–3 шага.
5. Локализация: английский и русский (String Catalog).
6. Иконка приложения и иконка в строке меню.
7. Автозапуск через `SMAppService`.

### Этап 5. Выпуск

1. Подпись Developer ID и нотаризация в CI.
2. Universal-сборка (arm64 + x86_64) и DMG.
3. Sparkle 2: appcast в GitHub Releases.
4. Homebrew cask.
5. Сайт-лендинг на GitHub Pages.

## Риски

| Риск | Что делать |
|---|---|
| Перенабор ломается в Electron, браузерах, терминалах | Задержки для каждой программы. Ручной тест-лист популярных программ |
| Ложные срабатывания раздражают сильнее пропусков | Консервативный порог, отмена одним нажатием, корпус тестов в CI |
| Права TCC слетают после обновления | Один Developer ID и один bundle ID с первого релиза |
| Лицензии словарей | Только данные с совместимой лицензией, источники в `data/SOURCES.md` |
| Event tap отключается системой при долгой обработке | Callback без тяжёлой работы. Переподключение по `tapDisabledByTimeout` |
