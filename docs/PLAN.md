# План Perekey

Perekey — свободный автоматический переключатель раскладки для macOS.
Ориентир по функциям — Caramba Switcher. Отличия: современный интерфейс,
гибкие сочетания клавиш, предсказуемость, проверяемая приватность, без подписки.

## Для кого и зачем

**Аудитория:**
- люди, которые пишут на русском и английском: мессенджеры, почта, документы;
- разработчики — им больнее всего от ложных срабатываний в коде и терминале;
- те, кто пересел с Windows и привык к ⌥⇧ / ⌃⇧;
- пользователи Punto Switcher: у него для Mac только сборка под Intel, без
  Rosetta он не запустится.

**Почему не системное переключение macOS:** в нём нет перенабора, нет
автопереключения и нет сочетаний из одних модификаторов, кроме Caps Lock и 🌐.

**Чем Perekey лучше бесплатного клона:**
1. **Предсказуемость.** Отмена одним Backspace. Отменённое слово запоминается
   и больше не переключается.
2. **Честный режим для кода.** В терминалах и IDE по умолчанию только ручное
   переключение.
3. **Проверяемая приватность.** Открытый код, набранный текст только в памяти,
   сеть только для проверки обновлений.

## Чистая комната

- Функции Caramba Switcher изучены по поведению и строкам интерфейса. Код и
  данные не декомпилировались.
- Правила и словари Caramba (`latest.clm`, `caramba.redb`) не копируем и не
  используем для обучения.
- Название и логотип Caramba не используем.
- Источник и лицензию каждого словаря записываем в `data/SOURCES.md`.

## Приватность

- Буфер слова живёт только в памяти. На диск набранный текст не попадает.
- Логи пишутся с `privacy: .private`. Набранный текст в логи не попадает.
- Сеть — только запрос appcast Sparkle. README называет этот адрес, чтобы
  его можно было проверить в Little Snitch.
- Нет телеметрии, Sentry и отправки слов.
- Экран «Что видит Perekey» простыми словами объясняет, какой доступ нужен и зачем.

## Сочетания клавиш

### Действия

| Действие | По умолчанию |
|---|---|
| Сменить раскладку по кругу | Shift |
| Перенабрать последнее слово или выделение | Option |
| Включить или выключить автопереключение | левый ⇧ + правый ⇧ |
| Включить конкретную раскладку | не задано |
| Вставить без форматирования | не задано |

### Пресеты

Код — `Sources/PerekeyCore/HotkeyPreset.swift`. Тест проверяет, что внутри
пресета ни одна комбинация не подходит под два действия.

| Пресет | Сменить раскладку | Перенабрать слово |
|---|---|---|
| `standard` (по умолчанию, как в Caramba) | Shift | Option |
| `doubleShift` | Shift | Shift дважды |
| `windowsAltShift` | ⌥⇧ | Option |
| `windowsControlShift` | ⌃⇧ | Option |
| `commandShift` | ⌘⇧ | Option |
| `separateKeys` | правый ⌘ → English, правый ⌥ → Русский | левый ⌥ |

Во всех пресетах левый ⇧ + правый ⇧ включает и выключает автопереключение.
Caps Lock — отдельная настройка (см. ниже).

**Онбординг спрашивает:** «Как вы привыкли менять раскладку?» Варианты: Shift,
как в Caramba; ⌥⇧ или ⌃⇧, как в Windows; ⌘⇧; отдельные клавиши; Caps Lock.

### Правила распознавания

Логика — `Sources/PerekeyCore/ChordDetector.swift`, покрыта тестами.

- Сочетание из одних модификаторов срабатывает на **отпускание**.
- Любой другой ввод при зажатых модификаторах отменяет сочетание: клавиша,
  клик, scroll, жест трекпада. Поэтому ⌘⇧4 — не ⌘⇧, ⌘-scroll — не ⌘,
  Shift+A — не Shift.
- Нажатие, начатое меньше чем через 0,15 с после другого ввода, не считается.
  Так Shift в быстром наборе не меняет раскладку посреди слова.
- Нажатие дольше 0,5 с не считается.
- Двойное нажатие — два одинаковых нажатия в пределах 0,4 с.
- Одиночное действие срабатывает сразу. Двойное действие не должно зависеть от
  того, что одиночное уже сработало: перенабор берёт раскладку слова из
  `WordBuffer`, а не текущую.
- Состояние модификаторов читаем из битов флагов каждого события
  (`ModifierKey.pressed(inEventFlags:)`), а не считаем нажатия и отпускания.
  Иначе после пропущенного события клавиша «залипнет».
- Левый и правый модификаторы различаются.

### Конфликты

Рекордер предупреждает, если сочетание уже занято:

| Сочетание | Где занято |
|---|---|
| ⌘Space | Spotlight |
| ⌃Space | Системная смена источника ввода |
| Shift дважды | Search Everywhere в JetBrains IDE |
| 🌐 / fn | Системное действие сработает тоже, раскладка сменится дважды |
| fn дважды | Диктовка |
| Модификатор дважды | Raycast, Alfred — если настроены |

### Caps Lock

- Вариант 1, без риска: включить системную настройку «Caps Lock переключает
  на ABC». Онбординг показывает, где она.
- Вариант 2, мгновенно: переназначить Caps Lock в F18 через `hidutil`.
  - Прочитать текущий `UserKeyMapping`, добавить своё, записать. Не затирать
    чужие переназначения.
  - Убрать своё при выходе.
  - Кнопка «Вернуть Caps Lock» в настройках — на случай падения.
  - Предупредить, если запущен Karabiner-Elements.

## Устройство

```
┌─ Perekey (приложение, MainActor) ──────────────────────┐
│ SwiftUI: MenuBarExtra, настройки, онбординг, подсказка  │
│ Настройки, исключения: JSON в Application Support       │
└──────────────┬─────────────────────────────────────────┘
               │ протоколы: TextSink, LayoutSwitcher, FocusObserver
┌─ PerekeyInput (системный слой) ─▼──────────────────────┐
│ EventTap — свой поток с CFRunLoop, не MainActor         │
│   keyDown, flagsChanged, клики, scroll, жесты           │
│   свои события помечены kCGEventSourceUserData          │
│   ввод пользователя придерживается во время перенабора  │
│ InputSources — TISCreateInputSourceList / Select        │
│ KeyTranslator — UCKeyTranslate: код клавиши → символ    │
│ Focus — активная программа, AXSecureTextField, каретка  │
│ SecureInput — IsSecureEventInputEnabled + PID владельца │
│ Permissions — AXIsProcessTrusted, CGPreflightListen…    │
└──────────────┬─────────────────────────────────────────┘
               │ простые значения: ModifierKey, код клавиши, bundle ID
┌─ PerekeyCore (чистая логика, без AppKit) ─▼────────────┐
│ ChordDetector, HotkeyPreset              ✔ готово       │
│ LayoutMap — коды клавиш ↔ символы для каждой раскладки  │
│ WordBuffer — коды клавиш текущего слова                 │
│ Classifier — n-граммы + словарь, сравнение двух чтений  │
│ AppModes, Exceptions — режимы программ, слова, отмены   │
│ Yofikator, DoubleCaps — правки текста                   │
└────────────────────────────────────────────────────────┘
```

### Ключевые решения

- **`WordBuffer` хранит коды клавиш, а не символы.** Клавиши `,` `.` `;` `'`
  `[` `]` в русской раскладке — буквы б ю ж э х ъ: «,eltn» → «будет».
  Граница слова зависит от раскладки, поэтому классификатор смотрит на оба
  прочтения одной последовательности нажатий.
- **Перенабор, порядок путей:**
  1. Основной: Backspace × N, затем ввод через `CGEventKeyboardSetUnicodeString`.
     Unicode-события не зависят от раскладки, нет гонки со сменой раскладки.
  2. Запасной, для терминалов, VM и удалённого рабочего стола: ввод кодами
     клавиш после смены раскладки, с задержками из настроек программы.
  3. По желанию для программы: AX-замена (`kAXSelectedTextRange` +
     `kAXSelectedText`) с проверкой чтением. Не основной путь: во многих
     программах AX ломает историю ⌘Z и форматирование, Electron поддерживает
     AX плохо.
- **Автодополнение.** В адресной строке браузера первый Backspace удаляет
  подсказку, а не символ. Нужен тест и, возможно, лишний Backspace для таких полей.
- **Перенабор выделения.** Сначала читать выделение через AX. Если не вышло —
  через буфер обмена: сохранить все типы, пометить временное содержимое
  `org.nspasteboard.TransientType` и `ConcealedType` (Maccy и Paste его не
  сохранят), потом восстановить.
- **Права.** Tap только для чтения требует Input Monitoring. Подмена и отправка
  событий требуют Accessibility. После выдачи доступа опрашивать
  `AXIsProcessTrusted` / `CGPreflightListenEventAccess` и пересоздавать tap без
  перезапуска программы.
- **Event tap.** Callback не делает тяжёлой работы. При `tapDisabledByTimeout`
  и `tapDisabledByUserInput` tap включается снова, а состояние модификаторов
  перечитывается из флагов.

### Классификатор

- Сравнивает log-вероятность двух прочтений: символьная n-граммная модель плюс
  бонус за слово из словаря.
- Учитывает язык предыдущего слова и режим программы.
- Решает на границе слова. Внутри слова переключает только на «невозможных»
  префиксах вроде «ghb».
- Отдельные случаи: однобуквенные «f» / «а», «b» / «и», аббревиатуры, «iPhone»,
  «ок», «Wi-Fi».
- Не трогает код, URL, пути, email, слова с цифрами.

**Метрика качества:**
- единица — слово;
- корпус — реальные ru и en тексты: переписка, статьи, код, сленг, имена;
- ошибки набора моделируются: тот же текст в неверной раскладке;
- считаем две величины: ложные срабатывания (верное слово переключено) и
  полноту (неверное слово исправлено);
- корпус прогоняется в CI на каждый PR, который трогает классификатор или данные.

### Этап 1. Ручное переключение

1. Вынести `PerekeyInput` отдельным target с протоколами `TextSink`,
   `LayoutSwitcher`, `FocusObserver`. Ядро тестируется на фейках.
2. Event tap на своём потоке: клавиши, модификаторы, клики, scroll, жесты.
3. Подключить `ChordDetector`.
4. `LayoutMap` из реальных раскладок системы через `UCKeyTranslate`.
5. `WordBuffer` на кодах клавиш. Сбрасывать на клике, стрелках, смене программы.
6. Перенабор слова: Backspace + Unicode-ввод. Метка своих событий, придержка ввода.
7. Перенабор выделения: AX, запасной путь через буфер обмена.
8. Поля паролей и Secure Input с именем программы.
9. Онбординг: доступ с живой проверкой, выбор пресета, демо-поле.
10. Меню: индикатор раскладки, пауза на час, автозапуск.
11. Экран сочетаний: пресеты, рекордер, конфликты, Caps Lock.

**Готово, когда:** Option исправляет «ghbdtn» на «привет» и «,eltn» на «будет»
в TextEdit, Safari, Telegram, VS Code и Terminal.

### Этап 2. Автопереключение

1. Собрать данные: частотные словари и n-граммы ru и en с совместимой
   лицензией. Источники в `data/SOURCES.md`.
2. Сделать `Classifier` и корпус для метрики.
3. Отмена Backspace и личные исключения из отмен.
4. Режимы программ, раскладка по умолчанию для программы.
5. Исключения для слов, пункт меню «Не переключать в этой программе».
6. Подсказка у курсора с кнопкой «отменить».
7. Экспорт и импорт JSON.

**Готово, когда:** на корпусе ложных срабатываний меньше 0,1 % слов при полноте
не ниже 95 %.

### Этап 3. Дизайн

1. Меню в строке меню: раскладка, режим текущей программы, быстрые переключатели.
2. Настройки: простой экран из трёх переключателей, расширенные — отдельно.
   Liquid Glass на macOS 26+.
3. Экран «Что видит Perekey».
4. Локализация: английский и русский (String Catalog).
5. Иконка приложения и иконка в строке меню.
