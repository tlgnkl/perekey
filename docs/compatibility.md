# Совместимость

Матрица: программа × функция. Одна таблица на версию macOS.

Знаки:

- ✔ — проверено, работает.
- ✔? — предварительно работает, нужно подтвердить.
- ✘ — не работает (в заметке: что именно).
- пусто — не проверялось.
- н/п — функция в программе не применима.

Как заполнять: запустить `scripts/e2e.sh`, остальное проверить руками по
`docs/manual-check.md`. В заметках писать версию программы и дату.

Функции:

- **Shift** — переключение раскладки.
- **Option** — перенабор последнего слова («ghbdtn» → «привет», «,eltn» → «будет»).
- **Option ×2** — повторный Option возвращает слово.
- **Быстрый набор** — «ghbdtn», Option, сразу «vbh»: выходит «привет мир», ни одна
  буква не осталась в старой раскладке.
- **Выделение** — перенабор выделенного текста.
- **Пароль** — в поле пароля раскладка не меняется, капсула показывает замок.

## Известные ограничения

- ⌘Z после перенабора откатывает ввод кусками. Исправить нельзя.
- В программе с автодополнением или автозаменой сверка может отменить
  перенабор. Это защита от порчи текста, а не ошибка.
- В поле пароля (Secure Input) macOS не отдаёт нажатия обычным способом.
  Раскладка там не меняется.
