# Числа стенда качества

Каждая таблица ниже подписана своей командой и коммитом. Коммит — дерево, на котором команда выполнена
(`77a29ae`: ветка `eval/pack` после слияния `origin/main`); после него менялись только документы. Модель —
`scripts/build-model.sh` на кэше данных `scripts/fetch-data.sh`: `en b748…`, `ru 84f3…`, `uk 3af4…` (хэши печатает
`run.json`). Лексикон — `.build/quality` (его строит `scripts/quality.sh` из того же кэша), как в CI. Tatoeba не
закреплён (`data/SOURCES.md`): снимок записан в `pack.json` пакета; другой снимок даст другие числа. Числа —
«первые» по пакету: планок они не двигают.

Первая версия этого документа играла пакет без лексикона, и столбцы «Т» и «Спорно» стояли нулями не по факту, а
по отсутствию меток. Эта версия играет с лексиконом: метки есть, вред стал меньше (спорные слова — опечатки
источника, а не вред).
