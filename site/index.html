Perekey

Набрали слово не в той раскладке? Perekey исправит. Typed it in the wrong layout? Perekey fixes it.

Бесплатный переключатель раскладки для macOS с открытым кодом. Живёт в строке меню и исправляет слово на лету или по сочетанию клавиш. A free, open-source keyboard layout switcher for macOS. It lives in the menu bar and fixes the word as you type or on a shortcut.

ПриватностьPrivacy

  • Набранный текст не сохраняется: слово живёт в памяти, пока вы его набираете.
  • На этом Mac лежат настройки и ваши списки слов («Мои», «Запомненные», «Всегда исправлять») с датами и числом отмен, счётчики правок, если вы их включили, и число слов каждого языка по программам. В счётчиках слов нет.
  • Единственный сетевой запрос: проверка обновлений. Её можно выключить, тогда сети нет совсем.
  • Нет телеметрии, отправки слов и идентификаторов устройства или установки.
  • Эта страница не использует трекеры, cookies и сторонние шрифты.
  • Typed text is never saved: the word lives in memory while you type it.
  • On this Mac Perekey keeps your settings and word lists (“Mine”, “Learned”, “Always fix”) with dates and undo counts, correction counts if you turn them on, and how many words of each language you type in each app. The counts hold no words.
  • The only network request is the update check. You can turn it off, and then there is no network use at all.
  • No telemetry, no sending of words, no device or install identifiers.
  • This page uses no trackers, no cookies and no third-party fonts.

УстановкаInstall

DMG

Скачайте образ из последнего выпуска и перетащите Perekey в «Программы». Рядом лежит файл с контрольной суммой SHA-256.Download the image from the latest release and drag Perekey to Applications. A SHA-256 checksum file sits next to it.

Homebrew

brew install --cask tlgnkl/tap/perekey

Perekey просит права «Универсальный доступ» и «Мониторинг ввода»: без них нельзя увидеть нажатия и заменить слово. Perekey asks for Accessibility and Input Monitoring: without them it cannot see keystrokes or replace a word.
